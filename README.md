# Ковёр бурения

Веб-модуль генерации ковра бурения: загружаете Excel со скважинами (формат ВПУ) —
и получаете график движения буровых установок: в каком порядке каждая БУ обуривает
кусты, с датами и количеством скважин. Плюс детальный ковёр по скважинам куста
и количественный режим «по суткам».

**Живая страница (после публикации):** https://alex91132.github.io/drilling-carpet/

Проект переосмысляет модуль планирования кустового бурения и язык графика
движения буровых установок (ГДБУ): фазы, даты «начало–конец», сутки по фазам,
буровые установки и бригады — но по каждой скважине выбранного куста.

## Возможности

| Блок | Что делает |
|---|---|
| **Режим «По установкам» (главный)** | Строка — буровая установка (с бригадой), зелёная полоса — кампания на кусте: последовательные скважины одной БУ на одном кусте, с датами начала/окончания и числом скважин. Паузы между кампаниями — переезд/простой; демонтаж и передвижка показаны отдельно. Зум колёсиком и перетаскивание по времени — то, чего нет в Excel. |
| **Парсер ВПУ** | Сам находит строку заголовков («Куст», «Номер скважины»…), определяет блоки фаз по объединённой строке выше заголовков и сопоставляет каждой фазе её даты и дни. **Порядок и состав столбцов могут быть любыми.** |
| **Режим «Календарь»** | Гант по реальным датам файла: монтаж → бурение → передвижка → ожидание/освоение → обустройство → ввод (флажок). Даты и сутки — как в ГДБУ. |
| **Режим «Циклы»** | Количественный ковёр: скважины последовательно, ось — накопленные сутки от начала бурения куста; зелёным — цикл бурения, серым — остальной цикл строительства. |
| **Детализация бурения** | Разбивка зелёного блока по секциям (направление, кондуктор, техническая, эксплуатационная колонна, хвостовик), если в файле есть даты по секциям. |
| **Сводка куста** | Скважины (доб/нагн), суммарная проходка, суммарные сутки бурения, средний цикл строительства, срок куста, задействованные БУ. |
| **Интерактив** | Тултипы с полной карточкой скважины и фазы, клики по легенде скрывают/показывают фазы, тёмная тема, экспорт ковра в PNG. |

Всё считается локально в браузере — файл никуда не отправляется.
Визуализация — чистый SVG без библиотек; Excel парсит SheetJS (CDN).

## Файлы

- `index.html` — страница: разметка, стили, парсер и рендер.
- `demo-data.js` — демо-данные (4 куста, 47 скважин; сгенерированы из
  реального файла ВПУ — кусты 24 БИС, 6Г, 108 Бис, 211 Бис).

## Ожидаемый формат входного файла

Лист, в первых 15 строках которого есть строка заголовков со столбцами
«Куст» и «Номер скважины», и строкой блоков фаз над ней (объединённые
ячейки «Бурение», «Монтаж», «Освоение», «Передвижка», «Ввод скважины…»,
«Демонтаж», «Обустройство», «Ожидание освоения», «Консервация»,
«Стаскивание БУ», «Бурение <колонны>»). Внутри блока распознаются
«Дата начала», «Дата окончания», «Количество дней», «Расстояние на передвижку».
Скважины могут идти группами по кустам (строка с одним заполненным «Куст») или
с заполненным «Куст» в каждой строке.

Если у скважины нет дат, но есть «Цикл бурения»/«Цикл строительства» —
она участвует в режиме «Циклы».

## Идеи развития

- Режим ГДБУ: ковёр по буровым установкам (несколько кустов, конфликты БУ).
- Проверка корректности: пересечения фаз, разрывы между скважинами, буровая
  «телепортируется» между кустами.
- Экспорт ковра обратно в Excel и сравнение план/факт по двум файлам.
- Оценка чувствительности: как сдвиг одной скважины двигает весь куст.
