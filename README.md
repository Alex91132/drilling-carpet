# Ковёр бурения

Веб-страница, которая из графиков бурения строит **график движения буровых установок (ГДБУ)** по месяцам:
в каком порядке каждая бригада обуривает кусты, даты начала и окончания бурения куста, число скважин,
вышкомонтажные работы (ВМР) между кустами и простой установки. Можно загрузить несколько файлов —
каждый становится секцией своего месторождения.

**Живая страница:** https://alex91132.github.io/drilling-carpet/

Простой буровой установки — одна из самых дорогих потерь в кустовом бурении. В Excel ГДБУ ведут вручную:
вписывают даты и кусты в объединённые ячейки и проверяют увязку переездов глазами. Здесь та же картинка
строится из исходного графика бурения, а ВМР раскладываются на работы по датам и простой.

## Что показывает

| Режим | Что видно |
|---|---|
| **Движение БУ (ГДБУ)** — главный | Строка — бригада, секции — месторождения, ось — месяцы с годами (период и ширина месяца настраиваются, прокрутка по горизонтали). Зелёный блок — бурение куста с подписью «КП (скважин)» и датами; жёлтый — ВМР, полоска снизу — демонтаж / переезд / монтаж по датам графика; штриховка — простой, промежуток без работ. Факт и план различаются насыщенностью, линия «сегодня». Клик по кусту — его ковёр. |
| **Скважины куста** | Гант по датам фаз: монтаж → бурение (по колоннам, если есть даты секций) → передвижка → освоение → обустройство → ввод. |
| **Циклы (сутки)** | Скважины куста подряд по накопленным суткам: цикл бурения и остальной цикл строительства. |

Сводка: установки, кампании, скважины, суммарные ВМР и простой. Предупреждения: у бригады пересекаются кусты
по времени, переход на новый куст без времени на ВМР. Экспорт в PNG.

## Логика

- **Установка = месторождение (файл) + номер бригады.** Номера бригад ведутся внутри месторождения: в графиках
  двух месторождений бригады 4, 8, 10 и 12 бурят одновременно — это разные установки. «Наименование вида БУ»
  в ключ не годится: у одной бригады оно меняется посреди куста (БУ 5000/320 → ZJ-40); заводской номер БУ
  в выгрузке тоже ненадёжен — по нему одна «установка» бурит два куста одновременно.
- **Кампания** — подряд идущие скважины одной бригады на одном кусте. Начало — начало бурения первой скважины,
  конец — окончание бурения последней. Даты — из «Дата начала / окончания цикла бурения» (заполнены у всех
  скважин), запасной вариант — блок «Бурение». Скважины куста без дат входят в число скважин кампании.
- **ВМР** — промежуток между кампаниями бригады. Внутри — работы с датами из графика: демонтаж и стаскивание
  на старом кусте, переезд, монтаж на новом. Часть промежутка, не покрытая ни одной работой, — простой.

## Проверка

`tests/index.html` — синтетические тесты ядра и сверка с ручным ГДБУ (эталон из Excel) на графиках двух
месторождений: порядок кустов совпал у всех бригад (75 кампаний), **все 49 фактических кампаний совпали
по датам начала и окончания (±1 день) и числу скважин**. Расхождения остаются только в плане после 2024 года —
ручной ГДБУ собран по другой версии плана. Сверка запускается, если в `data/fixtures/` есть выгрузки
(в git не попадают):

```bash
python tools/xlsx_rows.py "ВПУ.xlsx" data/fixtures/vpu.json
python tools/xlsx_rows.py "ТПУ.xlsx" data/fixtures/tpu.json
python tools/gdbu_expected.py "ГДБУ.xlsx" data/fixtures/gdbu.json
python -m http.server 8040        # и открыть http://localhost:8040/tests/
```

## Файлы

- `index.html` — страница: загрузка файлов, ГДБУ, ковёр куста, экспорт.
- `carpet-core.js` — ядро без DOM: разбор листа по заголовкам, кампании, ВМР, простой, проверки.
- `demo-data.js` — демо: графики бурения двух месторождений, только нужные странице столбцы
  (`tools/xlsx_rows.py --demo`; подрядчик, инвестпроекты, коды и номера оборудования не попадают).
- `tools/` — подготовка демо и фикстур (Python + openpyxl), `tests/` — тесты в браузере.

## Входной файл

Лист, в первых 15 строках которого есть строка заголовков с «Куст» и «Номер скважины» и строка блоков над ней
(объединённые ячейки «Бурение», «Монтаж», «Демонтаж», «Переезд», «Передвижка», «Освоение», «Ввод скважины…»,
«Обустройство», «Ожидание освоения», «Консервация», «Стаскивание БУ», «Бурение <колонны>»). Внутри блока
распознаются «Дата начала», «Дата окончания», «Количество дней». Порядок столбцов любой. Скважины могут идти
группами: строка-разделитель с названием месторождения или куста в столбце «Куст».

Всё считается в браузере — файлы никуда не отправляются. Excel читает SheetJS (CDN), графика — чистый SVG.
