Ковёр бурения

Загрузите графики бурения одного или нескольких месторождений — страница построит график движения буровых установок (ГДБУ) по месяцам: в каком порядке каждая бригада обуривает кусты, даты начала и окончания бурения куста, число скважин, вышкомонтажные работы между кустами и простой установки.

ГДБУ по месяцам несколько месторождений ВМР и простой установки проверка пересечений чистый JS + SVG

1 · Данные

Перетащите сюда графики бурения (.xlsx) — можно несколько
Каждый файл — своё месторождение (секция графика). Всё считается в браузере — файлы никуда не отправляются.
Нужны столбцы «Куст», «Номер скважины», «Номер бригады», «Дата начала / окончания цикла бурения» и блоки фаз с датами («Монтаж», «Демонтаж», «Бурение», …) — порядок столбцов любой.

2 · График

Загрузите файл — график появится здесь.

Как это работает

  • Установка = месторождение + номер бригады. Номера бригад в графиках бурения ведутся внутри месторождения: бригада 4 на одном месторождении и бригада 4 на другом бурят одновременно — это разные установки, поэтому каждый файл — своя секция графика. «Наименование вида БУ» в ключ не берётся: у одной бригады оно меняется посреди куста; в подписи — самый частый вид.
  • Кампания на кусте — подряд идущие скважины одной бригады на одном кусте. Начало — начало бурения первой скважины, конец — окончание бурения последней (по «Дате начала / окончания цикла бурения»; если её нет — по блоку «Бурение»). Скважины куста без дат входят в число скважин кампании.
  • ВМР и простой. Всё между кустами одной бригады — вышкомонтажные работы. Внутри промежутка отмечены работы, у которых в графике есть даты: демонтаж и стаскивание на старом кусте, переезд, монтаж на новом. Часть промежутка, не покрытая ни одной работой, — простой установки (штриховка): то, что стоит денег и что стоит сократить.
  • Проверки. Если у бригады кусты пересекаются по времени или переход на новый куст идёт без времени на ВМР, страница выводит предупреждение — так видны ошибки в графике до того, как они станут простоем.
  • Парсер — по заголовкам, а не по адресам ячеек. Строка заголовков ищется по «Куст» и «Номер скважины», блоки фаз — по объединённым ячейкам над ней. Строки-разделители с названием месторождения и куста распознаются. Сверено с ручным ГДБУ: все 49 фактических кампаний двух месторождений совпали по датам и числу скважин.
  • Скважины куста и циклы — детальный ковёр выбранного куста по датам фаз (монтаж → бурение → передвижка → освоение → ввод) и количественный режим по накопленным суткам.
  • Идея — из практики планирования кустового бурения: ГДБУ ведут в Excel вручную, вписывая даты и кусты в объединённые ячейки, а увязку переездов установок проверяют глазами.
